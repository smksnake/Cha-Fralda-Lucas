# 🎁 Chá de Bebê do Lucas

Bem-vindo ao repositório do site de sorteio de presentes para o chá de bebê do nosso pequeno **Lucas**! 💙

Este projeto foi desenvolvido com muito carinho para permitir que familiares e amigos que não puderem comparecer presencialmente ao chá ainda possam participar e nos ajudar com o enxoval.

## ✨ Funcionalidades

- **🎡 Roleta Interativa:** O convidado digita o nome e gira uma roleta animada para descobrir qual item do enxoval ele vai presentear.
- **🛒 Links Diretos:** Cada item sorteado vem com um link de sugestão de compra (Amazon) para facilitar a vida do convidado.
- **💸 Opção via PIX:** Para quem preferir não comprar o item físico (ou quiser economizar no frete), o site disponibiliza um QR Code e a chave PIX.
- **📦 Endereço de Entrega:** Botão para copiar o endereço completo de entrega com apenas um clique.
- **🔒 Painel do Papai:** Uma área restrita (protegida por senha) onde os pais podem ver a lista de quem já participou e o que cada um sorteou.
- **🎈 Chuva de Emojis:** Um fundo animado e temático com emojis de bebê, presentes e mamadeiras caindo em cascata.

## 🛠️ Tecnologias Utilizadas

Este é um projeto puramente Front-end (site estático), construído com:
- **HTML5** (Estrutura)
- **CSS3** (Estilização, animações da roleta e chuva de emojis)
- **JavaScript** (Lógica do sorteio, manipulação do DOM e uso do `localStorage` para salvar os dados)
- **GitHub Pages** (Hospedagem gratuita)
